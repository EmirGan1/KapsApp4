# High profile material sources

Worn Plaster Wall and Stone Floor, Poly Haven, CC0 1.0 Universal.

- https://polyhaven.com/a/worn_plaster_wall
- https://polyhaven.com/a/stone_floor
- https://creativecommons.org/publicdomain/zero/1.0/

Albedo, OpenGL normal and roughness maps retain 2048×2048 resolution and were encoded to WebP quality 95. Original download URLs and verified source MD5 hashes are in manifest.json. Bundled locally; no runtime external API calls. No Valve assets are included.
