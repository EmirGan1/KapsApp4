# Fresh practice, contextual word help and a calmer study interface

New vocabulary sessions now request a small batch of fresh contexts through the existing server-side German AI provider (Groq when configured). The learner's exact CEFR levels, direction, target words, category/unit scope, activity and Satzbau mode are preserved. Generation and review share a 28-second budget so queued work or provider failover cannot indefinitely delay a normal session. Generated items must pass structural validation, deterministic auditing and a separate semantic review before entering a session or the verified question bank. Provider errors, rate limits, malformed output and rejected candidates fall back to validated existing material. Resuming an active session preserves its questions instead of generating another batch. No new API key is sent to the browser.

Recent session snapshots now supply stable content identities and word exposure counts. UUIDs and shuffled options no longer disguise repeated questions. Matching sets and ordering tiles are included in identities; newly encountered content is preferred across A1–C1. Weak-word rotation leaves room for unseen words. Session novelty counts describe the questions actually selected, rather than successful generation attempts. Small finite pools (particularly articles and matching) can still repeat; normal five-answer mastery and deliberate review remain intact.

The new owner-scoped word-help endpoint supplies only safe, already visible German tokens before checking. Meaning-based tasks lock translations; hidden target tokens are omitted rather than transmitted as locked answers. After checking, a highlighted notice and word chips make meanings discoverable. Inline words support mouse hover, touch, keyboard focus and Escape. Sentence analysis adds the full corrected German expression, Turkish translation and every token in order, including repeated words and contextual phrase notes. Unknown dictionary meanings are explicitly unavailable rather than invented when AI is offline. Explanations use saved answers/results, reject unchecked or pending attempts, and stay unavailable during unfinished exams.

Practice now opens with four word activities and switches between word, sentence, listening and review groups. Difficulty and Satzbau controls live in an optional settings disclosure; audio downloads and Goethe modules are similarly secondary. Shorter copy, consistent surfaces, restrained accents and compact explanation cards preserve the six KapsApp themes. The practice category selector also now uses the normalized category IDs.

Validation: 38 German server/unit tests; 10 DM regression tests; TypeScript; production build; browser coverage of 11 activity types, answer/check/reload, reverse reinforcement, word-help lock/unlock and pointer/focus interactions, complete explanation rendering, grouped controls, and mobile/desktop layout across six themes. Provider generation/review and failure behavior use controlled transports; no production learner records or real paid Groq calls were used for these checks. Browser preparation polling can transiently return 404 before the server creates the progress row; recovery and modal completion are exercised.

Deployment uses the existing production setup and configured Groq credentials. No destructive migration or mastery reset is required.
